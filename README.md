# IdeaRadar

**From idea to opportunity.**

IdeaRadar is a cross-platform application for capturing, evaluating, and
tracking ideas from discovery to launch.

## Product status

Product specification and MVP planning.

## MVP principles

- Offline-first
- English-first and localization-ready
- Fast idea capture
- Evidence-based evaluation
- Simple, explainable scoring
- No account or backend required in version 1

## Planned stack

- Flutter
- Dart
- SQLite local database
- Android and iOS
