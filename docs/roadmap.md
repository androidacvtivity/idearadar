# IdeaRadar — Roadmap

## Phase 1 — Foundation

- Confirm product requirements.
- Create the Flutter project.
- Configure localization and application theme.
- Define domain models and local database schema.

## Phase 2 — Core MVP

- Ideas list
- Create and edit idea
- Idea details
- Evaluation form and automatic score
- Sources and notes
- Search, filtering, and sorting

## Phase 3 — Product validation

- Import representative CPMA Moldova ideas.
- Test on Samsung Galaxy A16.
- Test on iPhone 11.
- Use the app during ongoing market research.
- Record missing or unnecessary functions.

## Phase 4 — Optional online version

- PHP REST API
- MySQL database
- Authentication
- Device synchronization
- Backup and restore

Cloud features start only after the offline MVP proves the workflow.
