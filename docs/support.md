# IdeaRadar Support

IdeaRadar is an offline-first application for capturing, evaluating, and tracking ideas.

## Getting help

Before requesting support:

1. Confirm that the latest IdeaRadar version is installed.
2. Restart the application.
3. Include the device model, iOS version, and a short description of the problem.

To request support or report a problem, [open a GitHub issue](https://github.com/androidacvtivity/idearadar/issues/new).

## Data and backups

IdeaRadar stores its data locally on the device. The current version does not provide account synchronization or a cloud backup service. Removing the app may remove its local data.
